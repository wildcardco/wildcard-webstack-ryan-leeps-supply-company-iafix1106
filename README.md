# Leeps Supply Company — sample catalog

Vite + React + Tailwind sample storefront for Leeps Supply Company. This is a demo catalog, not the live Leeps checkout.

```bash
npm install
npm run dev
npm run build
npm run preview
```

- AKER BY MAAX 142038-000-002-084 (part 455593)
